# NAKKA DURGA SISINDRI — Portfolio

Static responsive portfolio using HTML, CSS and JavaScript. No Node.js or npm needed.

## Run locally
1. Open this folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**.
3. Or open `index.html` in your browser (Live Server is recommended).

## Files
- `index.html`: page content and sections
- `styles.css`: layout, colors, transitions, animations and responsive rules
- `script.js`: mobile menu, contact links, resume button, scroll reveals
- `Resume/DURGA_SISINDRI.pdf`: included resume

Verify your GitHub and LinkedIn URLs, the Bike EMI Calculator live link, and any project descriptions. Add project repository URLs when ready.
